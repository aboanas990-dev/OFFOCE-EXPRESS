# OFFICE EXPRESS

حزمة مكتبية عربية تعمل في المتصفح من ملف HTML واحد: مستندات، وجداول، وعروض، وقواعد بيانات، ونماذج، وتحليلات بيانات ولوحات معلومات تفاعلية.

> برمجة: حسن الفيفي · Hassan Alfaifi — للدعم: aboanas990@yahoo.com

## التشغيل
1. افتح `OFFICE-EXPRESS8.html` في Chrome أو Edge.
2. يحتاج اتصالًا بالإنترنت لتحميل المكتبات (SheetJS، mammoth، jsPDF، html2canvas، JSZip، PptxGenJS، Chart.js، sql.js، GSAP). إن تعذّر التحميل يظهر تنبيه «تعذر تحميل المكتبة اللازمة».
3. الملفات تُحفظ في متصفحك («ملفاتي المحفوظة») ويمكن تصديرها.

## الأقسام
- **المستندات:** تنسيق كامل، أنماط وعناوين، جداول وصور وروابط، فاصل صفحة، جدول محتويات، بحث واستبدال، عدد الكلمات، قراءة بصوت، اتجاه RTL/LTR. قوالب: خطاب رسمي، سيرة ذاتية، تقرير، فاتورة، كشف درجات، درس تعليمي…
- **الجداول:** صيغ ودوال، تنسيق الأرقام والعملة (ر.س)، فرز وإزالة تكرار، مخططات (أعمدة، أشرطة، خطي، دائري، حلقي، مساحي)، أوراق متعددة.
- **العروض:** شرائح بتخطيطات وسمات، أشكال ومربعات نص، انتقالات، ملاحظات المتحدث، وعرض من البداية أو من الشريحة الحالية.
- **قواعد البيانات والنماذج.**
- **التحليلات (جديد، 2026-10-28):** تقارير ولوحات معلومات تفاعلية بأسلوب Power BI داخل البرنامج:
  - **البيانات:** استيراد XLSX و XLS و CSV و JSON (مع «المستكشف» لاختيار الأوراق)، أو ورقة من تطبيق الجداول (زر «تحليل الورقة» في شريط الجداول)، أو جداول من تطبيق قواعد البيانات، أو لصق جدول، أو بيانات مبيعات تجريبية. عرض «البيانات» لتغيير نوع العمود وإعادة التسمية وحذف المكرر والفارغ والأعمدة المحسوبة.
  - **النموذج:** علاقات «متعدد ← واحد» بالسحب بين الجداول أو بالاكتشاف التلقائي، وتنتقل الفلاتر عبرها.
  - **المقاييس:** صيغ شبيهة بـ DAX: SUM و AVERAGE و COUNTROWS و DISTINCTCOUNT و SUMX و DIVIDE و IF و SWITCH و CALCULATE مع شروط، وأعمدة محسوبة تدعم RELATED.
  - **المرئيات (20 نوعًا):** بطاقة، بطاقة متعددة، أعمدة وأشرطة (عادية ومكدّسة)، خطي، مساحي، أعمدة وخط، دائري، حلقي، خريطة شجرية، قمعي، شلالي، مبعثر، مقياس، جدول، مصفوفة بتلوين حسب القيمة، مقسّم (قائمة، منسدلة، أزرار، نطاق)، ونص.
  - **التفاعل:** تصفية متقاطعة بالنقر، مقسّمات، فلاتر على مستوى المرئي والصفحة وكل الصفحات، تجميع التواريخ (سنة، ربع، شهر)، فرز وأعلى N، وضع التركيز، صفحات متعددة، سحب لنقل المرئيات وتغيير حجمها، تراجع وإعادة، سمات ألوان أولها هوية الشركة، وتقرير سريع تلقائي.
  - **التصدير:** PDF لكل الصفحات، صورة PNG، البيانات إلى Excel، بيانات المرئي CSV، وملف التقرير .oebi. التصدير يحتاج تجربة مجانية أو ترخيص Express Licence، وكل الأدوات الأخرى مجانية.
  - **الحفظ والمساعدة:** حفظ تلقائي في IndexedDB بالمتصفح، و Ctrl+S للحفظ في «ملفاتي المحفوظة». دليل استخدام عربي وإنجليزي من تبويب «مساعدة» أو F1.

## الترخيص والخصوصية
كل الأدوات تعمل دون ترخيص، وتنزيل الملفات وتصديرها يحتاج تجربة مجانية أو نسخة مفعّلة (Express Licence، معرّف التطبيق office-express). نافذة «حول» (زر HA) تعرض المطوّر والدعم ونوع الترخيص والشروط وسياسة الخصوصية. بياناتك لا تغادر متصفحك.
