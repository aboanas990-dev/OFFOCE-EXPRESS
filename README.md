# OFFICE EXPRESS

حزمة مكتبية عربية تعمل في المتصفح من ملف HTML واحد: مستندات، وجداول، وعروض، وقواعد بيانات، ونماذج.

> برمجة: حسن الفيفي · Hassan Alfaifi — للدعم: aboanas990@yahoo.com

## التشغيل
1. افتح `OFFICE-EXPRESS8.html` في Chrome أو Edge.
2. يحتاج اتصالًا بالإنترنت لتحميل المكتبات (SheetJS، mammoth، jsPDF، html2canvas، JSZip، PptxGenJS، Chart.js، sql.js، GSAP). إن تعذّر التحميل يظهر تنبيه «تعذر تحميل المكتبة اللازمة».
3. الملفات تُحفظ في متصفحك («ملفاتي المحفوظة») ويمكن تصديرها.

## الأقسام
- **المستندات:** تنسيق كامل، أنماط وعناوين، جداول وصور وروابط، فاصل صفحة، جدول محتويات، بحث واستبدال، عدد الكلمات، قراءة بصوت، اتجاه RTL/LTR. قوالب: خطاب رسمي، سيرة ذاتية، تقرير، فاتورة، كشف درجات، درس تعليمي…
- **الجداول:** صيغ ودوال، تنسيق الأرقام والعملة (ر.س)، فرز وإزالة تكرار، مخططات (أعمدة، أشرطة، خطي، دائري، حلقي، مساحي)، أوراق متعددة.
- **العروض:** شرائح بتخطيطات وسمات، أشكال ومربعات نص، انتقالات، ملاحظات المتحدث، وعرض من البداية أو من الشريحة الحالية.
- **قواعد البيانات والنماذج.**
